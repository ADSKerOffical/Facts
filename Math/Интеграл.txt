• Интеграл
     Интеграл – это сложение бесконечных кусочков в заданном радиусе с заданными правилами
        В нём используется буква d означает дифференциал. Она значит крошечный, бесконечно малый кусочек этой переменной, по которому ты суммируешь значение функции (по какой переменной идёт расчёт)
        А также x в интеграле это называется операндом
        
           ∫₀¹ [ 2dx ] = 2
           ∫₀² [ 2dx ] = 4
           ∫₀² [ (1 + x / 2) × dx ] = 3
         
        Для вычисления интегралов часто используют формулы Ньютона-Лейбница. Основная формула выглядит так (мне пришлось так записать а, потому что нету в юникоде символа subscript а):
           ∫(↓a)  ᷨf(x) × dx = F(b) - F(a)
        ? Первообразная это обратная операция дифференцирования
        Для операций есть собственные формулы:
        
           ∫ xⁿdx = xⁿ⁺¹ / n+1 + C где n ≠ -1
           ∫ 1/x × dx = ln|x| + C
           ∫ e ^ x × dx = e ^ x + C
           ∫ a ^ x × dx = a ^ x / ln(a) + C
           ∫ cos(x) × dx = sin(x) + C
           ∫ sin(x) × dx = -cos(x) + C
           ∫ 1 / sin²x × dx = tan(x) + C
           ∫ 1 / cos²x × dx = -cot(x) + C
           ∫ 1 / √(1 - x²) × dx = arcsin(x) + C
           ∫ 1 / √(1 + x²) × dx = arctan(x) + C
        
        Вот пример:
        
           ∫₀² [ x²dx ] = x³ / 3 |₀² = 2³ / 3 - 0³ / 3 = 8/3 - 0 = 2 × 2/3
           
        Также есть неопределённый интеграл (те примеры с операциями). Это набор всех первообразных функций для данной функции, который записывается как F(x) + C, где C — любое число
        В неопределенном интеграле C — это постоянная (константа) интегрирования. Она появляется из-за того, что при нахождении производной любое число равно нулю, и восстановить точное исходное слагаемое невозможно. C показывает, что интеграл задает целое семейство графиков, смещенных вертикально друг относительно друга
        Примеры:
           
           ∫ 2cdx = 2cx + C
           ∫ 1 / x²dx = -1 / x
