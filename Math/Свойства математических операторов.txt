• Свойства математических операторов

   Плюс (Сложение, Сумма):
       a + b = b + c
       a + 0 = 0
       a + (-a) = 0
   
   Минус (Вычитание, Разность):
       a - (-b) = a + b
       a - b = -(b - a)
       -(a - b + c) = -a + b - c
       -(-a) = a
       a - (-b) = a + b
   
   Умножение (Произведение): 
       a × b = a + a + a + ... (b раз)
       a × 1 = a; a × 0 = 0
       a × b = b × a
       a × -b = -(a × b) → 40 × -2 = -(40 × 2) = -80
      (a + b) × c = a × c + b × c → 361 × 11 = 361 × 10 + 361 × 1 = 3610 + 361 = 3920
      (a - b) × c = a × c - b × c
       a × b/n = a/n → 8 × 0.25 = 8 × 1/4 = 8/4 = 2
   
   Деление (Частное):
       a / 1 = a; 0 / a = 0; a / 0 = NaN; a / b ≠ b / a
       a / (b/n) = a × (n/b) 
       a × (b/c) = (a×b) / c
       a/b ÷ c/d = a/b × d/c
      (a + b) / c = a/c + b/c ; (a - b) / c = a/c - b/c
      (a × k) / b = k × (a/b) ; a / (b × k) = 1/k × (a/b)
       a = b × q + r, где (0 ≤ r ≤ b; r – остаток, q – неполное частное)
       
   Степень:
       aⁿ = a × a × a × ... (n раз)
       a⁰ = 1; a¹ = a
       aⁿ × aᵐ = aⁿ⁺ᵐ
       (aⁿ)ᵐ = a ^ (n × m)
       a⁻ⁿ = 1 / aⁿ
        
   Корень (Радикал):
       ⁿ√a = a ^ (1/n)
       (ⁿ√a)ᵐ = a ^ (m/n)
       ⁿ√(a × b) = ⁿ√a × ⁿ√b
       (ⁿ√a)ᵐ = ⁿ√(aᵐ)
       ᵐ√(ⁿ√a) = ᵐⁿ√a
       ⁿ√(aⁿ) = |a| if a % 2 == 0 else a
       a × ⁿ√b = ⁿ√(aⁿ × b)
       
   Логарифм:
       log(n)ₙ = 1
       log(a × b)ₙ = log(a)ₙ + log(b)ₙ
       log(a / b)ₙ = log(a)ₙ - log(b)ₙ
