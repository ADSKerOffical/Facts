• Число Армстронга

      Число Армстронга — это число, которое равно сумме своих цифр, возведенных в степень, равную количеству цифр в нем, например, 153, 370 и 371
      Примеры:
          153 = 1³ + 5³ + 3³
          370 = 3³ + 7³ + 0³ = 27 + 343 + 0
          407 = 4³ + 0³ + 7³ = 64 + 343 + 0
      Все однозначные цифры являются числом Армстронга
