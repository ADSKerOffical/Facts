• Горячие клавиши

     • Телефоны
         Сделать скриншот: уменьшение громкости + кнопка питания
         Экстренное выключение: уменьшение громкости + кнопка питания (зажать 10-15 сек)
         Вызвать ассистента (нейросеть): зажать кнопку питания
         Показать кнопку перезагрузки и выключения: зажать увеличение громкости + кнопку питания

     • Windows
         Скопировать текст: Ctrl + C
         Вставить текст: Ctrl + V
         Закрытие всех программ: Alt + F4
         Скриншот с возможностью выделения: Win + Shift + S
         Скриншот полного экрана: Win + PrtScn
         Открыть панель с эмодзи: Win + .
         Удалить файл: кликнуть один раз и нажать Shift + Delete
         Открыть или закрыть кнопку пуска: Win
         Переключить на экран блокировки: Win + L
         Открыть буфер обмена: Win + V
         Открыть системное окно "Выполнить": Win + R. У неё такие режимы:
         
             cmd – открывает командную строку (терминал)
             calc – запускает калькулятор
             notepad – открывает блокнот
             control – открывает классическую панель телефона
             charmap – открывает таблицу символов
             
        Открыть диспетчер задач: Ctrl + Shift + Esc
        Открыть терминал с правами администратора: Win + R, написать cmd, Ctrl + Shift + Enter
        Получить айпи адреса доменов, через который идёт трафик: F12 → Network (Нажми F5 чтобы обновить список)
