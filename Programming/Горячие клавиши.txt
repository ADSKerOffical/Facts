• Горячие клавиши

     • Телефоны
         Сделать скриншот: уменьшение громкости + кнопка питания
         Экстренное выключение: уменьшение громкости + кнопка питания (зажать 10-15 сек)
         Вызвать ассистента (нейросеть): зажать кнопку питания
         Показать кнопку перезагрузки и выключения: зажать увеличение громкости + кнопку питания
         Открыть Recovery Mode: зажать кнопку питания и увеличения громкости до появления логотипа 
         Закрыть Recovery Mode: выбрать пункт Reboot system now и нажать кнопку питания 
         Вызвать kernel panic: запустить это (нужны рут права) – echo c > /proc/sysrq-trigger
         Секретные звонки (Samsung):
             *#9900# – открыть SysDump
             *#1234# – подробная информация о CSC
             *#0*# – открыть глубокое системное меню диагностики
         Секретные звонки (Redmi/Xiaomi):
             *#*#6484#*#* – открывает меню CIT
             *#*#6485#*#* – скрытое меню батареи
             *#*#4636#*#* – информация о сети
             *#*#284#*#* – создание системного отсчёта
         Безопасный режим: перезагрузить и во время логотипа зажать кнопку уменьшения звука
         Отключить безопасный режим: просто перезагрузи телефон
         Открыть Fastboot: зажать кнопку питания и уменьшения громкости 
         Закрыть Fastboot: зажать кнопку питания 15-20 секунд

     • Windows
         Скопировать текст: Ctrl + C
         Вставить текст: Ctrl + V
         Закрыть все окна: Alt + F4
         Скриншот с возможностью выделения: Win + Shift + S
         Скриншот полного экрана: Win + PrtScn
         Открыть панель с эмодзи: Win + .
         Удалить файл (без возможности восстановления): кликнуть один раз и нажать Shift + Delete
         Открыть или закрыть кнопку пуска: Win
         Переключить на экран блокировки: Win + L
         Открыть буфер обмена: Win + V
         Переключить язык: Shift + Ctrl
         Включить/Выключить режим диктора: Win + Enter
         Экстренная перезагрузка: зажать кнопку питания 5-10 секунд
         Открыть системное окно "Выполнить": Win + R. У неё такие режимы:
         
             cmd – открывает командную строку (терминал)
             calc – запускает калькулятор
             notepad – открывает блокнот
             control – открывает классическую панель телефона
             charmap – открывает таблицу символов
             
        Открыть диспетчер задач: Ctrl + Shift + Esc
        Открыть терминал с правами администратора: Win + R, написать cmd, Ctrl + Shift + Enter
        Получить айпи адреса доменов, через который идёт трафик: F12 → Network (Нажми F5 чтобы обновить список)
        
        Открыть синий экран безопасности (через обычный скрипты невозможно заблокировать): Ctrl + Alt + Delete
        Перезагрузить видеодрайвер: Win + Ctrl + Shift + B
        Запустить безопасный режим (WinRE): Зажать Shift + Кнопку перезагрузки (в меню пуск) или сделать 3 экстренных перезагрузок подряд
        Перезагрузить текущую страницу или окно: F5
        Открыть БИОС: перезагрузить и во время загрузки быстро нажимать F2 или Delete
        Открыть планировщик задач: Win + R и ввести taskschd.msc
        Посмотреть автозагрузки: Win + R и ввести shell:startup
        Вызвать синий экран смерти: запустить этот скрипт (от имени администратора) – taskkill /f /im csrss.exe
        Запустить программу от имени администратора: Ctrl + Shift + Enter
