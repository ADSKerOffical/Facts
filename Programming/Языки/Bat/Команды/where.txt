where
    where – команда, которая ищет файлы по их имени и возвращает их полный путь
    Например: where notepad. Если такого файла нету, то выводит ошибку на экран и её код (в виде переменной errorlevel), но это можно исправить с опцией: where /q <имя_команды>
    
    Вот пример:
        where /q git.exe
        if %errorlevel%==0 (
          echo Git установлен
        ) else (
          echo Git не найден
        )
        
    В линуксе используется другой аналог: whereis
