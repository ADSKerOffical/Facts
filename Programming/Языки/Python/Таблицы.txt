Таблицы
   В Python есть три вида таблицы: список (list), кортеж (tuple), словарь (dict)
      Чтобы создать список, нужно использовать квадратные скобки; чтобы кортеж, то круглые скобки; чтобы словарь, то фигурные скобки
         Список можно изменять и там все индексы числовые
         Кортеж это как список, но только нельзя изменить значения, только саму переменную
         Словарь может иметь как числовые, так и строчные индексы. Изменяемый
         
         a = [1, "b", True, []]
         b = (1, "b", True, (1,))
         c = {"a": 1, "b": "bb", "c": True}
         
         Чтобы создать пустой картеж или картеж с одним элементом, то нужно просто поставить запятую в скобках
