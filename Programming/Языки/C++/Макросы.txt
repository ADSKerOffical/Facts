Макросы
   Макросы – это правила текстовой подстановки, которые препроцессор выполняет в исходном коде до того, как программа начнет компилироваться
      Они задаются через #define. А также их можно делать мини функциями:
      
          #include <iostream>
          #define PI 3.14159
          #define SQUARE(x) ((x) * (x))

          int main() {
	           std::cout << PI << std::endl; // 3.14159
	           std::cout << SQUARE(3.0) << std::endl; // 9
	           // PI = 4; – вызовет ошибку
	           return 0;
          }
          
      Их нельзя изменить в коде и при попытке изменить вызовет ошибку
      Однако их можно удалить с помощью #undef (пример: #undef PI)
      Ещё существует #if, #elif, #endif, #ifndef (if not defined), #ifdef и т.д и по аналогии они тоже запускаются до компиляции
