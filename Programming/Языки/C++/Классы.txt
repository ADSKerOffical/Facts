Классы
   Классы – это пользовательский тип данных, который служит шаблоном или «чертежом» для создания объектов
      Он объединяет в себе данные (переменные-члены, или поля) и функции для работы с ними (методы)
      Класс позволяет скрывать внутренние детали реализации и защищать данные от некорректного изменения. Для этого используются модификаторы:
      
          public – открытый интерфейс, доступный из любого места программы
          private (по умолчанию) – члены класса видны только внутри самого класса
          protected – члены видны внутри класса и в классах-наследниках
      
      Пример (отступы не обязательно делать):
      
         class Counter {
           private:
              int value = 0;
           public:
              void increment() {
                 value++;
              }
              int get() const {
                 return value;
              }
         };
      
      Но чисто использовать вот таким образом нельзя 
      Чтобы создать объект нужно его создать таким образом:
      
         Counter c1; // теперь есть объект c1 с типом Counter
         for (int i = 1; i <= 5; i++) {
            c1.increment()
         }
         std::cout << c1.get() << std::endl; // 5
         
      Ключевое слово static внутри класса делает поле или метод общим для всего класса, а не принадлежащим конкретному объекту (c1, c2 и т.д)
      Обычные поля (как value в моём примере) создаются заново для каждого объекта, а static существует в единственном экземпляре на всю программу
      
         class Counter {
            private:
              int value = 0;
              static inline int totalCounters = 0;
              static inline long long totalClicks = 0;
            
            public:
              Counter() { // вызывается при создании нового объекта. Если есть аргументы, то нужно использовать Counter c1(); а если нету аргументов, то Counter c1;
                 totalCounters++;
              } 
              // кстати, если функцию Counter привязать к части private, то создать новый объект с таким классом вызовет ошибку
              
              void click() { 
                value++; 
                totalClicks++; // можно использовать
              }
              int get() { return value; }
         };
      
      Статический метод можно вызвать через имя класса, даже если не создано ни одного объекта
      Ограничение работает только в обратную сторону: статический метод не видит обычные поля, а вот обычный метод видит всё
      
      Через метод Counter c1 объект не удастся удалить обычными способами
      Однако можно создать динамичный класс используя указатель:
      
          Counter* c3 = new Counter;
          c3 -> click(); // запускается. Все правила с видимостью переменных и т.д здесь тоже работают
          std::cout << c3 -> get() << std::endl; // 1
          delete c3; // теперь c3 больше нет
