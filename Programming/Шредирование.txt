• Шредирование
      Шредирование – удаление файла с диска навсегда
      Когда ты удаляешь файл обычным способом (Shift + Delete) то на этот файл просто удаляется ссылка и диск ждёт пока будет новый файл
      ? HDD использует вращающиеся магнитные пластины и механическую головку, работает медленно, очень чувствителен к ударам и падениям (особенно во время работы), но стоит дешевле
      Его можно уничтожить таким образом (HDD):
          1. Содержимое файла перезаписывается случайными байтами, нулями или специальными масками. Для надежности этот процесс может повторяться несколько раз (от 1 до 35 в зависимости от стандарта)
          2. Имя файла меняется на случайный набор символов, чтобы скрыть исходное название
          3. Файл удаляется из файловой системы стандартным путем
      Однако этот метод не работает для SSD. Для такой видеокарты вообще ручным способом очень сложно сделать универсальное шредирование 
      ? SSD работает на микросхемах памяти, более устойчив к падениям и файлы открываются мгновенно, но и стоит больше
          1. Скачать утилиту (Линукс) через sudo: hdparm (для SATA SSD) или nvme-cli (для NVMe SSD)
          2. Найти название диска через lsblk
          3. Для NVMe активировать это: sudo nvme format /dev/nvme0n1 --namespace-id=1 --ses=1  |  (это имя это для примера, у тебя должно быть другое имя) А для SATA накопителя это: sudo hdparm -I /dev/sda
